# Infinity Import S.A. — Sistema de Gestión de Inventario

Proyecto académico de Organización Empresarial.
Tecnicatura Universitaria en Programación — UTN.

## Descripción del proyecto

Infinity Import S.A. se dedica a la comercialización de artículos
para el hogar, cocina, limpieza, organización y decoración.

El proyecto propone desarrollar un Sistema de Gestión de Inventario
en Python para consultar existencias, registrar entradas y salidas,
detectar faltantes y facilitar la reposición de mercadería.

Este repositorio reúne la documentación técnica del proyecto
desarrollada en las Entregas 1, 2, 3 y 4.

## Funcionalidades previstas

- Consulta de productos y stock disponible.
- Registro de entradas y salidas de mercadería.
- Actualización de existencias.
- Alertas de faltantes.
- Consulta de proveedores y alternativas de abastecimiento.
